# 儿童任务积分兑换系统 - Agent 分析文档

## 1. 项目概述

### 1.1 项目名称
儿童任务积分兑换系统（Kids Task & Reward System）

### 1.2 项目定位
一款面向儿童（6-12岁）的日常任务管理与积分激励软件，旨在通过游戏化方式培养良好习惯，帮助家长管理儿童日常活动。

### 1.3 目标用户
| 角色 | 描述 |
|------|------|
| 儿童用户 | 执行任务、积累积分、兑换奖品的主要使用者 |
| 管理员（家长） | 管理任务模板、商品库存、审核兑换申请、查看数据 |

### 2.2 模块依赖关系

- **用户中心**：基础模块，其他所有模块依赖用户身份认证
- **任务模块**：依赖用户中心，产生积分变更
- **时间模块**：依赖用户中心，独立运行，触发提示逻辑
- **商城模块**：依赖用户中心，依赖商品数据
- **兑换模块**：依赖用户中心、商城模块、任务模块（积分校验）

## 3. 功能模块详细说明

### 3.1 任务模块（Task Module）

#### 3.1.1 功能描述
以“任务卡”形式展示每日任务，支持手动输入自定义任务，并提供打卡标记功能。

#### 3.1.2 核心功能点
| 功能 | 描述 | 输入 | 输出 |
|------|------|------|------|
| 查看今日任务 | 展示当天的任务列表 | 用户ID，日期 | 任务列表 |
| 添加自定义任务 | 儿童/家长手动输入新任务 | 任务标题，描述，预估积分 | 新建任务记录 |
| 打卡任务 | 标记任务为已完成 | 任务ID，用户ID | 更新任务状态，增加积分 |
| 删除任务 | 删除未完成的任务 | 任务ID | 删除记录 |
| 获取任务统计 | 获取指定日期范围内的完成情况 | 用户ID，起止日期 | 统计数据 |

#### 3.1.3 数据模型（简化）
```json
{
  "task_id": "uuid",
  "user_id": "uuid",
  "title": "string",
  "description": "string",
  "points": "integer",
  "status": "pending|completed|cancelled",
  "date": "YYYY-MM-DD",
  "created_at": "timestamp",
  "completed_at": "timestamp"
}
3.1.4 业务规则
每个任务每天只能打卡一次

任务完成后积分自动累加到用户总积分

可设置任务为“每日重复”类型

3.2 时间模块（Time Module）
3.2.1 功能描述
手动记录作业完成时间和游戏游玩时间，并在时间达标时触发提示。

3.2.2 核心功能点
功能	描述	输入	输出
开始计时	开始记录某项活动的时间	用户ID，活动类型（作业/游戏）	计时会话ID
结束计时	结束计时并记录时长	计时会话ID，结束时间	更新记录
手动输入时长	直接输入活动时长	用户ID，活动类型，时长(分钟)	新增记录
达标检测	检测作业或游戏是否达标	用户ID，活动类型，目标值	布尔值 + 提示信息
获取今日时长汇总	显示今日各类活动总时长	用户ID	汇总数据
3.2.3 数据模型（简化）
json
{
  "record_id": "uuid",
  "user_id": "uuid",
  "activity_type": "homework|game",
  "duration_minutes": "integer",
  "date": "YYYY-MM-DD",
  "start_time": "HH:MM",
  "end_time": "HH:MM",
  "is_target_reached": "boolean"
}
3.2.4 业务规则
作业达标阈值：默认 60 分钟/天（可配置）

游戏达标阈值：默认 30 分钟/天（可配置）

游戏时间超过阈值时触发警告提示

作业时间达到阈值时触发鼓励提示

同一活动类型同一时间只能有一个进行中的计时

3.3 商城模块（Shop Module）
3.3.1 功能描述
提供商品浏览、加入购物车、选购功能。

3.3.2 核心功能点
功能	描述	输入	输出
商品列表	展示可兑换商品	分类过滤条件	商品列表
商品详情	查看商品详细信息	商品ID	商品详情
加入购物车	将商品加入购物车	用户ID，商品ID，数量	更新购物车
移除购物车	从购物车移除商品	用户ID，商品ID	更新购物车
修改购物车数量	更改商品数量	用户ID，商品ID，数量	更新购物车
获取购物车	查看当前购物车内容	用户ID	购物车详情
3.3.3 数据模型（简化）
json
// 商品
{
  "product_id": "uuid",
  "name": "string",
  "description": "string",
  "price_points": "integer",
  "category": "toy|game_time|activity|other",
  "stock": "integer",
  "image_url": "string",
  "is_active": "boolean"
}

// 购物车
{
  "cart_id": "uuid",
  "user_id": "uuid",
  "items": [
    {
      "product_id": "uuid",
      "quantity": "integer",
      "added_at": "timestamp"
    }
  ],
  "updated_at": "timestamp"
}
3.4 兑换模块（Redemption Module）
3.4.1 功能描述
提供商品兑换页面，支持兑换玩具、电脑游玩时间等虚拟/实物奖品。

3.4.2 核心功能点
功能	描述	输入	输出
提交兑换订单	使用积分兑换商品	用户ID，商品ID，数量	兑换订单
兑换记录查询	查看历史兑换记录	用户ID，状态过滤	记录列表
兑换详情	查看兑换订单详情	订单ID	订单详情
取消兑换	取消未处理的兑换申请	订单ID	更新状态，返还积分
管理员审核	管理员处理兑换请求	订单ID，状态(approved/rejected)	更新订单状态
3.4.3 数据模型（简化）
json
{
  "redemption_id": "uuid",
  "user_id": "uuid",
  "product_id": "uuid",
  "quantity": "integer",
  "total_points_used": "integer",
  "status": "pending|approved|rejected|completed",
  "created_at": "timestamp",
  "processed_at": "timestamp",
  "admin_notes": "string"
}
3.4.4 业务规则
兑换时校验用户积分是否充足

兑换成功后扣减用户积分

虚拟商品（如游戏时间）兑换成功后自动增加对应配额

实物商品需要管理员审核并确认发放

3.5 用户中心（User Center Module）
3.5.1 功能描述
提供快捷操作入口、数据显示（积分、时间统计）、个人资料管理。

3.5.2 核心功能点
功能	描述	输入	输出
查看积分余额	显示当前总积分	用户ID	积分余额
积分明细	查看积分变动历史	用户ID，分页参数	积分流水
今日数据概览	显示今日任务/时间统计	用户ID	统计面板数据
本周数据汇总	显示本周任务/时间趋势	用户ID	图表数据
个人资料编辑	修改用户信息	用户ID，更新字段	更新结果
快捷打卡入口	快速打卡常用任务	用户ID，任务ID	打卡结果
数据导出	导出任务/时间/兑换数据	用户ID，时间范围	导出文件
3.5.3 数据模型（简化）
json
{
  "user_id": "uuid",
  "username": "string",
  "avatar": "string",
  "total_points": "integer",
  "role": "child|parent|admin",
  "settings": {
    "homework_target": 60,
    "game_target": 30,
    "daily_task_reminder": "boolean"
  },
  "created_at": "timestamp"
}

6. 非功能性需求
6.1 性能要求
页面加载时间 < 2 秒

打卡操作响应时间 < 500ms

支持同时在线用户数 ≥ 100

6.2 安全要求
用户数据隔离，儿童只能查看自己的数据

积分变动需要记录详细日志

管理员操作需要审计日志

6.3 可用性要求
界面色彩丰富、适合儿童使用

图标为主，文字为辅

操作反馈清晰（成功/失败提示）

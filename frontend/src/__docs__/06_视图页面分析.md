# 06 - 视图页面分析

## 一、视图页面架构

视图页面位于 `src/views/` 目录下，按业务模块分组：

```
views/
├── Home/              # 首页
│   ├── home.vue
│   └── components/    # 子组件
├── Product/           # 商品详情
│   ├── product.vue
│   └── components/    # 子组件
├── Filter/            # 图书筛选
│   ├── filter.vue
│   └── components/    # 子组件
├── Cart/              # 购物车
│   ├── cart.vue
│   └── components/    # 子组件
├── Checkout/          # 结算页
│   ├── checkout.vue
│   └── components/    # 子组件
├── Orders/            # 订单页
│   ├── orders.vue
│   └── components/    # 子组件
├── Profile/          # 个人中心
│   ├── profile.vue
│   └── components/    # 子组件
├── Seller/           # 卖家中心
│   ├── seller.vue
│   └── components/    # 子组件
├── Admin/            # 管理后台
│   ├── admin.vue
│   └── components/    # 子组件
├── Auth/             # 认证页面
│   ├── login.vue
│   ├── register.vue
│   ├── forget.vue
│   ├── adminLogin.vue
│   └── seller.vue
├── Help/             # 帮助页面
│   └── help.vue
└── NotFound/         # 404页面
    └── notfound.vue
```

## 十三、页面组件设计模式

### 13.1 标准页面结构
```vue
<script setup lang="ts">
// 1. 引入子组件
import SubComponent from './components/SubComponent.vue'

// 2. 引入 Store
import { useSomeStore } from '@/stores/someStore'

// 3. 初始化 Store
const someStore = useSomeStore()

// 4. 组件挂载时获取数据
onMounted(async () => {
  await someStore.fetchData()
})
</script>

<template>
  <div class="page__container">
    <!-- 页面内容 -->
    <SubComponent />
  </div>
</template>

<style scoped lang="scss">
.page__container {
  // 页面容器样式
}
</style>
```

### 13.2 数据获取模式
```typescript
onMounted(async () => {
  try {
    loading.value = true
    await store.fetchData(params)
  } finally {
    loading.value = false
  }
})
```

## 十四、视图与 Store 交互

```
views/*
    │
    ├── 调用 Store 方法获取数据
    │
    ▼
stores/*
    │
    ├── 调用 API Service
    │
    ▼
apis/services/*
    │
    ├── 发送 HTTP 请求
    │
    ▼
Backend API
```

### 14.1 典型交互示例
```typescript
// views/Product/product.vue
const bookStore = useBookStore()

// 获取商品详情
onMounted(async () => {
  const route = useRoute()
  await bookStore.getBookDetailById(route.params.id)
})
```

# 校园闲置图书交易平台 - 前端项目分析

## 一、项目概述

**项目名称**: Express-vue3-mysql（校园闲置图书交易平台前端）  
**项目类型**: 前后端分离的电商平台 Web 应用  
**技术栈**: Vue 3 + TypeScript + Vite + Pinia + Vue Router + Element Plus  
**目标用户**: 大学生（买家/卖家）、平台管理员、物流配送员

## 三、核心功能模块

### 3.1 用户认证模块
- **功能**: 用户登录、注册、密码找回、卖家认证
- **核心文件**: `stores/auth.ts`, `apis/services/auth.ts`, `views/Auth/*`
- **权限角色**: student(学生), admin(管理员), maxAdmin(超级管理员), transporter(物流)

### 3.2 图书交易模块
- **功能**: 图书浏览、筛选搜索、商品详情、购买下单
- **核心文件**: `stores/book.ts`, `apis/services/book.ts`, `views/Filter/*`, `views/Product/*`
- **特点**: 支持分类筛选、条件搜索、图书详情展示

### 3.3 购物车模块
- **功能**: 添加购物车、数量修改、优惠券应用、多店铺结算
- **核心文件**: `stores/cart.ts`, `views/Cart/*`, `views/Checkout/*`
- **特点**: 按商家分组、支持优惠券自动推荐

### 3.4 订单管理模块
- **功能**: 订单创建、支付、发货、收货、取消
- **核心文件**: `stores/orders.ts`, `apis/services/order.ts`, `views/Orders/*`
- **特点**: 完整订单流程、多状态管理、线下线上交易

### 3.5 个人中心模块
- **功能**: 用户信息管理、收货地址、收藏、优惠券
- **核心文件**: `stores/user.ts`, `stores/address.ts`, `stores/favorite.ts`, `stores/coupon.ts`

### 3.6 卖家中心模块
- **功能**: 商品上架下架、订单管理、优惠券发行、财务统计
- **核心文件**: `views/Seller/*`

### 3.7 管理后台模块
- **功能**: 用户管理、商家管理、订单管理、图书审核、数据统计
- **核心文件**: `stores/admin.ts`, `apis/services/admin.ts`, `views/Admin/*`

## 四、路由架构

### 4.1 路由分组
| 路由前缀 | 布局组件 | 认证要求 | 主要功能 |
|---------|---------|---------|---------|
| `/` | UserLayout | 需要登录 | 首页、商品详情、个人中心、购物车等 |
| `/auth` | AuthLayout | 不需要 | 登录、注册、找回密码、卖家认证 |
| `/admin` | AdminLayout | 管理员权限 | 管理后台各项功能 |

### 4.2 路由守卫机制
1. **白名单检查**: 公开路由直接放行
2. **登录状态验证**: 未登录重定向到登录页
3. **角色权限检查**: 管理员/卖家/普通用户权限分级
4. **卖家身份二次验证**: 本地存储的卖家状态可能过期，需服务端验证

## 五、状态管理架构

### 5.1 Store 列表
| Store | 主要职责 | 持久化方式 |
|-------|---------|-----------|
| auth | 用户认证、Token管理、权限判断 | localStorage |
| user | 用户信息管理 | localStorage |
| book | 图书数据、筛选、推荐 | 内存 |
| cart | 购物车、商品选择、优惠券 | localStorage |
| orders | 订单列表、状态管理 | 内存 |
| favorite | 收藏列表 | localStorage |
| coupon | 优惠券管理 | 内存 |
| address | 收货地址管理 | localStorage |
| review | 评论数据 | localStorage |

### 5.2 跨 Store 依赖
- `auth` 是核心 Store，其他 Store 可能依赖其获取用户ID和权限信息
- `cart` 在登录时调用 `switchUser()` 切换用户数据

## 六、API 请求架构

### 6.1 HTTP 封装
- 基于 Axios 封装，统一配置 baseURL、timeout、headers
- 请求拦截器：自动添加 Token（白名单除外）
- 响应拦截器：统一处理 code === 0 的成功响应

### 6.2 服务模块化

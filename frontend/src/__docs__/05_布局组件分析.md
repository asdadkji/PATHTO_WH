# 05 - 布局组件分析

## 一、布局组件架构

布局组件位于 `src/layouts/` 目录下，为不同模块的页面提供统一的布局结构：

```
layouts/
├── Admin/               # 管理后台布局
│   ├── AdminLayout.vue
│   └── components/
│       ├── AdminNav.vue
│       └── AdminFooter.vue
├── Auth/                # 认证页面布局
│   ├── AuthLayout.vue
│   └── components/
│       ├── AuthNav.vue
│       └── AuthFooter.vue
├── User/                # 用户主布局
│   ├── UserLayout.vue
│   └── components/
│       ├── UserNav.vue
│       └── UserFooter.vue
└── Empty/               # 空布局（404等）
    ├── EmptyLayout.vue
    └── components/
        ├── EmptyNav.vue
        └── EmptyFooter.vue
```

---

## 二、用户布局 (UserLayout)

### 2.1 组件结构
```vue
<script setup lang="ts">
import UserNav from '@/layouts/User/components/UserNav.vue'
import UserFooter from "@/layouts/User/components/UserFooter.vue";
</script>

<template>
  <UserNav></UserNav>
  <router-view></router-view>
  <UserFooter></UserFooter>
</template>
```

### 2.2 布局特点
- **Header**: UserNav 顶部导航栏
- **Content**: `<router-view>` 路由内容区
- **Footer**: UserFooter 底部信息栏

### 2.3 对应路由
此布局用于需要登录的用户页面，包括：
- 首页 (`/home`)
- 商品详情 (`/product/:id`)
- 购物车 (`/cart`)
- 结算页 (`/checkout`)
- 订单页 (`/orders`)
- 个人中心 (`/profile/*`)
- 卖家中心 (`/seller/*`)

## 三、管理后台布局 (AdminLayout)

### 3.1 组件结构
```vue
<script setup lang="ts">
import AdminNav from "@/layouts/Admin/components/AdminNav.vue";
import AdminFooter from "@/layouts/Admin/components/AdminFooter.vue";
import list from '@/views/Admin/components/list.vue'
</script>

<template>
  <AdminNav></AdminNav>
  <list style="margin: 16px"></list>
  <AdminFooter style="margin-top: 400px"></AdminFooter>
</template>
```

### 3.2 布局特点
- **Header**: AdminNav 管理导航
- **Sidebar**: list.vue 侧边菜单栏组件
- **Footer**: AdminFooter 底部栏
- **Content**: 右侧主内容区域

### 3.3 对应路由
此布局用于 `/admin/*` 路径下的管理功能页面：
- 仪表盘 (`/admin/dashboard`)
- 用户管理 (`/admin/users`)
- 商家管理 (`/admin/sellers`)
- 买家管理 (`/admin/buyers`)
- 订单管理 (`/admin/ordersA`)
- 物流管理 (`/admin/transport`)
- 图书审核 (`/admin/bookReview`)
- 图书管理 (`/admin/bookMgt`)

## 四、认证布局 (AuthLayout)

### 4.1 组件结构
```vue
<script setup lang="ts">
import AuthNav from "@/layouts/Auth/components/AuthNav.vue";
import AuthFooter from "@/layouts/Auth/components/AuthFooter.vue";
</script>

<template>
  <AuthNav></AuthNav>
  <router-view :key="$route.fullPath"></router-view>
  <AuthFooter></AuthFooter>
</template>
```

### 4.2 特殊设计
- **`:key="$route.fullPath"`**: 路由切换时强制重新渲染组件，确保登录/注册/找回密码等页面切换时状态重置

### 4.3 对应路由
此布局用于 `/auth/*` 路径下的认证相关页面：
- 用户登录 (`/auth/login`)
- 管理员登录 (`/auth/adminLogin`)
- 用户注册 (`/auth/register`)
- 忘记密码 (`/auth/forget`)
- 卖家认证 (`/auth/sellerAuth`)

## 九、布局与路由对应关系

```
┌─────────────────────────────────────────────────────────────────┐
│                         UserLayout                              │
│  ┌─────────────────┬────────────────────────┬───────────────┐ │
│  │   UserNav       │    <router-view>       │  UserFooter   │ │
│  │  (顶部导航)      │    (动态页面内容)        │  (底部)       │ │
│  └─────────────────┴────────────────────────┴───────────────┘ │
│                              ↑                                  │
│  /home, /product/:id, /filter   ←  publicRoutes               │
│  /cart, /orders, /checkout      ←  mainRoutes (需登录)        │
│  /profile/*                    ←  mainRoutes (需登录)        │
│  /seller/*                     ←  mainRoutes (需卖家权限)     │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                         AuthLayout                              │
│  ┌─────────────────┬────────────────────────┬───────────────┐ │
│  │   AuthNav       │    <router-view>       │  AuthFooter   │ │
│  │  (顶部导航)      │    (key=$route.fullPath) │  (底部)       │ │
│  └─────────────────┴────────────────────────┴───────────────┘ │
│                              ↑                                  │
│  /auth/login, /auth/register, /auth/forget, /auth/sellerAuth   │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                         AdminLayout                             │
│  ┌─────────────────┬────────────────────────┬───────────────┐ │
│  │   AdminNav      │    list.vue (侧边栏)    │               │ │
│  │  (顶部导航)      │    + <router-view>     │  AdminFooter  │ │
│  │                 │    (主内容区)           │               │ │
│  └─────────────────┴────────────────────────┴───────────────┘ │
│                              ↑                                  │
│  /admin/dashboard, /admin/users, /admin/sellers, ...          │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                         EmptyLayout                             │
│                    <router-view>                                │
│                              ↑                                  │
│  /404, /:pathMatch(.*)*                                       │
└─────────────────────────────────────────────────────────────────┘
```

## 十、布局切换机制

### 10.1 路由配置中的布局指定
```typescript
// router/index.ts
{
  path: '/',
  component: UserLayout,    // 用户布局
  children: [...]
},
{
  path: '/auth',
  component: AuthLayout,    // 认证布局
  children: [...]
},
{
  path: '/admin',
  component: AdminLayout,   // 管理布局
  children: [...]
}
```

### 10.2 布局选择逻辑
```
用户访问 URL
       ↓
路由匹配找到对应的 Layout 组件
       ↓
Layout 组件渲染其专属的 Nav + Footer
       ↓
<router-view> 渲染对应的页面组件
```

## 十一、响应式设计

### 11.1 布局响应式策略
- **UserLayout**: 适配桌面端，1200px 内容宽度
- **AdminLayout**: 固定侧边栏 + 弹性内容区
- **AuthLayout**: 居中内容，响应式宽度

### 11.2 样式实现
```scss
.home__container {
  width: 100%;
  margin: 0 auto;
  .home__middle {
    display: flex;
    width: 1200px;  // 最大宽度限制
    margin: 0 auto;
  }
}
```

## 三、Vite 构建配置 (vite.config.ts)

### 3.1 插件配置
```typescript
plugins: [
  vue(),                                    // Vue 3 支持
  vueDevTools(),                           // Vue DevTools 调试
  AutoImport({ resolvers: [ElementPlusResolver()] }),  // 自动导入 API
  Components({ resolvers: [ElementPlusResolver()] })    // 自动导入组件
]
```

### 3.2 路径别名配置
```typescript
resolve: {
  alias: {
    '@': 'src',                             // 源代码根目录
    'components': 'src/components',         // 组件目录
    'views': 'src/views',                   // 视图目录
    'utils': 'src/utils',                   // 工具目录
    'apis': 'src/apis',                     // API 目录
    '@assets': 'assets',                    // 资源目录
    'lodash': 'lodash-es'                   // Lodash 别名
  }
}
```

### 3.3 开发服务器配置
```typescript
server: {
  port: 8080,           // 开发端口
  host: '0.0.0.0',     // 允许外部访问
  open: true,           // 自动打开浏览器
  cors: true,           // 允许跨域
  proxy: {
    '/api': {
      target: 'http://localhost:3000',  // API 代理目标
      changeOrigin: true,
      secure: false
    }
  }
}
```

### 3.4 生产构建配置
```typescript
build: {
  outDir: 'dist',           // 输出目录
  minify: 'terser',         // 使用 Terser 压缩
  rollupOptions: {
    manualChunks: {
      'vue-vender': ['vue', 'vue-router', 'pinia'],  // Vue 核心 chunk
      'ui-library': ['element-plus'],                 // UI 库 chunk
      'utils': ['lodash-es', 'dayjs', 'axios'],        // 工具库 chunk
      'editor': ['@wangeditor/editor']                 // 编辑器 chunk
    }
  }
}
```

### 3.5 SCSS 预处理器配置
```typescript
css: {
  preprocessorOptions: {
    scss: {
      additionalData: `@use "@assets/styles/abstracts" as *; @use "@assets/styles/base" as *;`
    }
  }
}
```
每个 SCSS 文件自动导入抽象变量和基础样式。

## 八、分析总结

### 8.1 项目初始化流程
```
index.html
    ↓
main.ts (创建应用)
    ├── 引入 Pinia 状态管理
    ├── 引入 Vue Router 路由
    ├── 引入 Element Plus UI
    ├── 注册 Element Plus 图标
    └── 挂载 App 组件到 #app
```

### 8.2 关键技术特点
1. **自动化导入**: 通过 unplugin 自动导入 API 和组件，减少手动 import
2. **代码分割**: 生产构建按功能模块分块，优化加载性能
3. **SCSS 抽象**: 全局样式变量和混合器集中管理
4. **代理转发**: 开发环境通过 Vite 代理解决跨域问题
5. **类型安全**: 完整的 TypeScript 配置确保类型检查

# 07 - 通用组件分析

## 一、通用组件架构

通用组件位于 `src/components/` 目录下，按功能分组：

```
components/
├── form/              # 表单相关组件
│   ├── address.vue    # 地址表单
```

## 二、表单组件 (form/)

### 2.1 地址表单组件 (form/address.vue)

#### 功能
- 新增收货地址
- 编辑已有地址
- 设置默认地址
- 地址验证

#### 核心逻辑
- **表单项**: 收货人姓名、电话、详细地址
- **特殊标记**: 是否设为默认地址、是否设为发货地址

### 2.2 评论表单组件 (form/review.vue)

#### 功能
- 商品评论发布
- 评分选择
- 标签选择
- 图片上传（可选）
- 匿名评论设置

#### 核心逻辑
- **评分**: 1-5 星评分
- **标签选择**: 物流快、包装完好、服务态度好等预设标签
- **评论内容**: 文字评价，可选是否匿名

## 五、工具函数 (utils/)

### 5.1 本地存储封装 (utils/localstorage.ts)

#### 功能
- 统一 localStorage 读取/写入/删除
- 自动 JSON 序列化/反序列化
- 错误处理

#### 代码实现
```typescript
const storage = {
  get: (key: string): any => {
    try {
      const item = localStorage.getItem(key)
      return item ? JSON.parse(item) : null
    } catch (e) {
      console.log('读取本地存储失败：', e)
      return null
    }
  },
  set: (key: string, value: any) => {
    try {
      localStorage.setItem(key, JSON.stringify(value))
    } catch (e) {
      console.log('写入本地存储失败：', e)
    }
  },
  remove: (key: string) => {
    try {
      localStorage.removeItem(key)
    } catch (e) {
      console.log('删除本地存储失败：', e)
    }
  }
}
```

#### 使用场景
| Key | 用途 |
|-----|------|
| `token` | JWT 用户令牌 |
| `user` | 用户基本信息 |
| `is_seller` | 卖家身份状态 |
| `user_info` | 完整用户信息 |
| `cart:list:{userId}` | 用户购物车 |
| `favorite:list` | 收藏列表 |
| `addresses_{userId}` | 用户地址列表 |
| `claimedCoupons` | 已领取优惠券 |

## 六、样式资源 (assets/styles/)

### 6.1 目录结构
```
assets/styles/
├── abstracts/         # 抽象资源
│   ├── _index.scss    # 导出文件
│   ├── _mixins.scss   # 混合器
│   └── _variables.scss # 变量
├── base/             # 基础样式
│   ├── _index.scss    # 导出文件
│   └── _reset.scss    # CSS 重置
├── main.scss         # 主样式入口
└── element-cover.scss # Element Plus 覆盖样式
```

### 6.2 变量文件 (_variables.scss)
定义全局样式变量：
- **颜色变量**: 主色、辅助色、背景色、文字色
- **字体变量**: 字体族、字号、字重
- **间距变量**: 常用间距值
- **圆角变量**: border-radius 值
- **阴影变量**: box-shadow 值

### 6.3 混合器文件 (_mixins.scss)
定义可复用的样式混合器：
- **响应式混合器**: 媒体查询封装
- **文本省略**: 单行/多行文字省略
- **Flex 布局**: 常用 Flex 模式
- **按钮样式**: 基础按钮样式

### 6.4 重置文件 (_reset.scss)
CSS 重置和基础样式：
- **box-sizing**: border-box
- **margin/padding**: 清除默认间距
- **列表样式**: 清除默认列表样式
- **链接样式**: 清除默认链接样式

### 6.5 主样式入口 (main.scss)
```scss
// 导入顺序很重要
@use 'abstracts/variables' as *;
@use 'abstracts/mixins' as *;
@use 'base/reset';

// 全局组件样式覆盖
@use 'element-cover';
```

### 6.6 Element Plus 覆盖 (element-cover.scss)
覆盖 Element Plus 默认样式，保持项目统一性。

## 九、组合式函数规范

### 9.1 useSprite 实现模式
```typescript
// composables/svg/useSprite.ts
export function useSprite() {
  const sprites = ref<Map<string, string>>(new Map())

  const addSprite = (name: string, content: string) => {
    sprites.value.set(name, content)
  }

  const getSprite = (name: string) => {
    return sprites.value.get(name)
  }

  return {
    sprites: readonly(sprites),
    addSprite,
    getSprite
  }
}
```

### 9.2 使用示例
```typescript
const { addSprite, getSprite } = useSprite()

// 添加图标
addSprite('cart', '<svg>...</svg>')

// 获取图标
const cartIcon = getSprite('cart')
```

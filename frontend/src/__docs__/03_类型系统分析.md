# 03 - 类型系统分析

## 一、类型定义架构

TypeScript 类型定义位于 `src/types/` 目录下，按功能分为以下模块：

```
types/
├── api/           # API 请求/响应类型
├── entities/      # 数据实体类型
├── forms/         # 表单数据类型
├── store/         # Store 状态类型
├── common/        # 通用类型（分页、响应）
└── index.ts       # 统一导出
```

---

## 二、API 类型 (types/api/)

### 2.1 认证类型 (types/api/auth.ts)

```typescript
// 登录参数
export interface LoginParams {
  username: string;
  password: string;
}

// 注册参数（继承登录参数）
export interface RegisterParams extends LoginParams {

// 重置密码参数
export interface ResetPwdParams {

// 认证响应
export interface AuthToken {
  token: string;
  user: {
    id: number;
    username: string;
    phone: number;
  }
}
```

### 2.2 图书类型 (types/api/book.ts)

```typescript
// 图书基础接口
export interface Books {
  id: number;
  title: string;              // 书名
  author: string;             // 作者
  publisher: string;          // 出版社
  isbn: string;               // ISBN
  edition: string;            // 版次
  publish_year: number;       // 出版年
  original_price: string;     // 原价
  price: string;              // 售价
  book_condition: 'new' | 'very_good' | 'good' | 'acceptable' | 'poor';  // 书籍品相
  status: 'available' | 'sold' | 'reserved';  // 状态
  category_id: number;        // 分类ID
  book_type: string;          // 书籍类型
  subject: string;            // 学科
  course_name: string | null; // 课程名
  tags: string[];             // 标签
  cover_image: string;        // 封面图
  images: string[];           // 详情图
  description: string;        // 描述
  highlights: string;        // 亮点
  defects: string | null;    // 缺陷
  transaction_methods: string[];  // 交易方式
  location: string;          // 位置
  can_deliver: number;       // 是否可配送
  delivery_fee: string;      // 配送费
  seller_id: number;         // 卖家ID
  merchant_id: number;       // 商家ID
  campus_id: number;         // 校区ID
  view_count: number;        // 浏览次数
  favorite_count: number;    // 收藏次数
  inquiry_count: number;     // 咨询次数
  is_featured: number;       // 是否推荐
  is_urgent: number;        // 是否急售
  is_negotiable: number;     // 是否可议价
  expires_at: string;       // 过期时间
  created_at: string;        // 创建时间
  updated_at: string;        // 更新时间
}

// 分页响应
export interface BookPage {
  books: {
    rows: Books[];
    total: number;
  }
}

// 首页推荐图书（精简版）
export interface Book_Recommend {
  id: number;
  title: string;
  author: string;
  price: string;
  cover_image: string;
  created_at: string;
  category_id: number;
}

// 分组书籍
export interface GroupedBook {
  [categoryId: string]: Book_Recommend[];
}

// 图书详情
export interface BookDetails {
  booksAll: Books;
}
```

## 八、类型系统使用规范

### 8.1 类型导入方式
```typescript
// 从 api 类型导入
import type { Books, BookPage } from '@/types/api/book.ts'

// 从 store 类型导入
import type { CartItem } from '@/types/store'

// 从实体导入
import type { User } from '@/types/api/user.ts'
```

### 8.2 类型定义位置选择
| 场景 | 推荐位置 |
|-----|---------|
| API 请求/响应 | `types/api/` |
| 表单数据 | `types/forms/` |
| Store 状态 | `types/store/` 或 Store 文件内 |
| 业务实体 | `types/entities/` |

## 九、类型检查流程

```
代码编写 → TS 编译检查 → vue-tsc type-check → 构建输出
    ↓
  类型错误 → 提示修正 → 重新检查
```

项目中配置了 `npm run build` 包含 `vue-tsc --build` 进行完整的类型检查。
